# Anurag Juyal — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `anurag-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No build tools or package installation are required.

## Customize before publishing
- In `index.html`, replace `your.email@example.com` with your real email address.
- Verify project links and add/remove projects based on your latest work.
- Update the education, internship, hackathon and achievement details as needed.
- Add a resume PDF and link it from the hero section if you want a downloadable CV.

## Deploy
You can deploy this static site using GitHub Pages, Netlify or Vercel. Upload the three website files (`index.html`, `style.css`, `script.js`) to your repository or static hosting provider.
